# Leap Holo Gram Prototype

## Overview
This project is a prototype for a hologram display using **Leap Motion** and a **hologram pyramid**. It demonstrates interactive holographic visuals viewable through the pyramid setup.

---

## Setup Instructions

1. **Download and Extract**  
   Download the project files and extract them to a folder on your computer.

2. **Open in Unity**  
   Open Unity Hub and load the project folder.

3. **Open Prototype Scene**  
   Navigate to:  Assets/LeapHolo/Holo.unity


   Open this scene to view the prototype.

---

## Important Notes

- **Leap Motion Device Required**  
The prototype requires a connected Leap Motion device. If errors occur, ensure you update the Leap Motion API to the latest version.

- **Unity Version Compatibility**  
Some files may cause errors if opened with older Unity versions. Fix any Leap Motion file errors before running the program.

- **Error Warnings**  


Leap Motion - Device is Required - Update API


Resolve this warning by updating Leap Motion assets and scripts.

---

## Running the Prototype

1. Fix all Leap Motion errors in Unity.
2. Ensure the Leap Motion device is connected.
3. Play the scene in Unity. The hologram interactions will start automatically.
